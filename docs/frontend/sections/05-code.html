Postgres failover

Promote the standby, repoint writers, and verify replication lag is zero. Last used 2 days ago during INC-2036.

Steps

  1. Confirm the primary is down
    Two consecutive health-check failures, 30s apart.airp db:health --primary
  2. Stop writes on the old primary
    Fence it so it cannot accept writes after promotion.airp db:fence --target primary
  3. Promote the standby
    Wait for promotion to report ready before continuing.airp db:promote --standby standby-1 --wait
  4. Repoint the writers
    Update the connection string in the vault; services pick it up on next deploy.airp vault:rotate db-writer --value $NEW_PRIMARY_DSN
  5. Verify replication lag is zero
    Fail the runbook if lag exceeds 5s after 2 minutes.airp db:lag --expect 0
  6. Announce in #incidents
    Post the failover summary and new primary endpoint.
