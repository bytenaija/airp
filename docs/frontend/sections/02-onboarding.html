Step 2 · Code

Connect GitHub

Install the AIRP GitHub App so agents can read your code, review every pull request, and open fixes as pull requests.

AIRP GitHub App

Read-only by default. AIRP requests write access only on repositories where you enable autofix pull requests.

  • Agents search and read your codebase with full file context during investigations.
  • Every pull request gets reviewed against your production topology.
  • Verified fixes open as pull requests, ready for your team to merge.
Step 3 · Infrastructure

Connect your cloud

Pick a provider. AIRP syncs your resources into a live topology and watches them for anomalies around the clock.

Clouds with queryable logs and metrics (AWS, Cloudflare, Vercel, Fly.io, Render, Kubernetes) already count as a telemetry source, so you can start without a separate observability tool.

Step 4 · Telemetry

Connect observability

Pipe logs, metrics, and alerts into AIRP so every investigation cites real evidence instead of guessing.

Step 5 · Team

Connect Slack

Get incident alerts where your team already works. Mention AIRP in a channel and the answer arrives in a thread.

Slack workspace

AIRP posts incident alerts, investigation summaries, and approval requests to the channels you choose.

  • Incident alerts land in #incidents with severity, service, and a link to the investigation.
  • Approve or reject fixes with one click from the Slack message.
  • Ask AIRP anything from any channel; answers arrive in a thread.
